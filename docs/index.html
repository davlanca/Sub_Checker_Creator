Своя подписка (необязательно)

Если хочешь проверить не список из репозитория, а свою подписку - вставь ее сюда: ссылку на файл подписки (https://...), сами ссылки vless/vmess/trojan/ss или просто host:port, каждая с новой строки. Проверка с телефона пойдет по ней.

Полная проверка (пинг, скорость, доступность из России) идет на GitHub Actions - для нее нужна именно ссылка на подписку, а не сами конфиги. Результат появится в таблице ниже.

Запустить полную проверку на сервере

Кнопка выше проверяет только доступность с телефона. Полная проверка (пинг, скорость, доступность из России) идет на GitHub Actions каждые 15 минут. Чтобы запустить ее прямо сейчас, нужен токен GitHub - он хранится только в этом браузере и никуда не отправляется, кроме api.github.com.

Как сделать токен

GitHub - Settings - Developer settings - Personal access tokens - Fine-grained tokens - Generate new token. Репозиторий: davlanca/Sub_Checker_Creator. Права: Repository permissions - Actions: Read and write. Остальное не трогай.

Честное ограничение: браузер не умеет делать полное VLESS-подключение и мерить скорость через прокси. Поэтому "пинг" и "скорость" в таблице - от серверного чекера, "из России" - от check-host.net, а "с телефона" - живая проверка доступности с твоего устройства. Вместе это отвечает на вопрос, работает ли сервер именно у тебя. Для своей подписки пинг и "из России" берутся из проверки с телефона или из серверной проверки кнопкой "Проверить подписку на GitHub", а скорость в браузере померить нельзя.
